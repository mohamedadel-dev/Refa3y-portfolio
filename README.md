# Mohamed Adel El Refaey — Portfolio

A responsive bilingual (English/Arabic) personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example: `mohamed-portfolio`).
2. Extract this ZIP on your computer.
3. Upload the **contents** of the `mohamed-portfolio` folder (the `index.html`, `style.css`, `script.js`, and `assets` folder) to the repository root. Do not upload only the ZIP file.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two; GitHub will show the published website URL in Settings → Pages.

## Customize
- Edit text and links in `index.html`.
- Replace `assets/profile.jpg` to change the profile photo (keep the same filename).
- Edit colors and layout in `style.css`.
- Edit language toggle behavior in `script.js`.

Review role titles, dates, and descriptions before publishing publicly.
